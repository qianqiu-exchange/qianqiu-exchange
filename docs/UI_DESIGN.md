# V0.3.1 市井手记 · UI 与字体改版

2026-10-29。用户要求参照 https://vibe-design-labs.github.io/Vibe-UI-UX/ 的 UI 和字体，直接改当前游戏。

## 任务和判断

目标：手机竖屏中的玩家能从纸上市场手记进入闲谈、查看报价并完成实际交易或支援。已观察：旧版是深色面板；参考站使用米色纸面、墨绿区块、朱砂按钮、毛笔标题和文楷正文。设计推断：统一这套视觉语言可让历史题材更有辨识度；未进行真人测试，不能声称已提高留存或理解率。

## 页面与组件规则（本次方案值）

| 位置 | 实际修改 | 验收 |
| --- | --- | --- |
| 页头 | 千秋双字印章、毛笔品牌、小字市场手记 | 手机不撑宽 |

| 导航 | 墨绿当前页，横向手机导航自动保留当前项可见 | 六页分别检查 |

来源标签：W4 统一字体/颜色/组件重复；K4 具体操作名称与支出说明；E2 朱砂焦点与角色语气；布局、字号和验证方式为技能综合方案 S，未当作书中规范。

## 实际走查与修订

1. 看参考站实际桌面截图并核对字体来源及许可，使用同源字体重新生成游戏子集。
2. 发现手机双栏大标题折成四行：缩小手机毛笔字号，调整双栏比例，阶段缩短为“开盘布局”等。
3. 发现 360 像素筛选按钮被通用最小宽度撑出页面：限定筛选按钮尺寸后重新检查。
4. 切到末尾页签后，当前页签可能被横向导航遮住：渲染后仅调整导航自身滚动，不滚动整页。
5. 实际完成闲谈、买粮、取消/重做分配、观察对手、交付结算、跨季营地归还、八季结束、存档导入导出和旧入口。
