# V0.2 增量说明（2026-10-28）

新增 `tavern.js` 与 `ai.js`，保持纯静态、可直接打开、可部署 GitHub Pages。三位酒馆消息人提供每回合固定线索；玩家有两次探访，可将线索分享给接管原价值账户的沈砚。对手可选择 BYOK 或预设策略，订单仍经过原交易引擎；不会让模型修改价格、余额或结算结果。保留三名规则型 NPC。

新增回合对话、有限信念变化、历史交涉记忆与线索复盘。V0.1 存档缺少酒馆字段时自动补全，不增加资金。Key 只保存在页面内存；玩法请求支持超时、取消与失败后的预设策略。共创提案增加草稿版本检查，避免覆盖生成期间或生成后发生的编辑。

验证命令：`node --test tests/engine.test.cjs tests/tavern.test.cjs`（35/35 通过）；`node tests/browser-smoke.cjs`（配置 Playwright 与浏览器后运行，18/18 通过）。实际单元测试输出见 `../test-results.txt`，浏览器结果见 `browser-test-results.json`，预览见 `tavern-preview.png` 与 `tavern-mobile-preview.png`。BYOK 使用模拟返回测试，未调用真实付费服务。旧预览图保留为 V0.1 历史材料。

# V0.1 原型相对 PRD V1.0 的范围变更

为了第一轮交付**可双击运行的本地游戏**，特意采用无依赖的原生 JavaScript、HTML 和 CSS。引擎与界面已经分文件，市场公式及主要交易规则来自 PRD，但尚未完成正式版所要求的 TypeScript 包化与全量自动化检查。

| 项目 | PRD V1.0 目标 | 当前实际交付 |
| --- | --- | --- |
| 基础交易 | LMSR、费用、市场、份额 | 已实现，15 项 Node 测试 |
| 人物股 | 成分组合及分红 | 已实现本地原子交易与除权 |
| NPC | 4 类、可复现、无未来结果输入 | 已实现；不依赖 LLM |
| 时间 | 8 回合手动推进 | 已实现 |
| 存档 | IndexedDB、版本迁移、强校验 | 自动存档与 JSON 导入导出已实现；迁移不完整 |
| 历史内容 | 史料核验、可扩展剧本 | 示例剧本已实现；史料尚未审校 |
| 用户体验 | React + TS + Vite + PWA | 零依赖静态 HTML；未使用框架和 Service Worker |
| 回放 | 完整操作日志与状态哈希重放 | 固定种子确定性运行，记录日志；独立回放器未完成 |
| 社区 | JSON 投稿协议 | JSON 本地编辑、校验、导入/导出 |
| BYOK | 共创 Agent | 仅可选生成历史情报修改提案，需人工批准 |
| 共享市场 | V1 不做 | 没有多人联网或在线排名 |

**免责声明**：当前资料仅作为历史游戏的测试剧情草稿；不能用演示中的史料条目替代逐条考据。此包没有上线网站或发布 GitHub 仓库。
