# V0.3 架空世界实现记录

2026-10-29。已按用户最新授权在原项目修改入口与新增世界引擎。V0.2完整目录备份保存在本机工作区 `work/before-sandbox-v0.2`，未推送或部署。

新增文件：world-scenario.js、world.js、world-app.js、world.css、world-connections.js、tokenpay.js、AGENT_SETUP.md、agent-setup.json及对应测试。index.html成为架空入口；classic.html保留原入口。ai.js添加TokenPay归因与明确恢复提示，原调用协议回归通过。

资产与货币账本分别守恒。资源仓单交付后计入消耗量；营地经营份额从可用持仓移到锁定，费用从阵营金库支付，归还时保留原账面成本。全资产估值先合并同标的数量再计算净平仓价，避免分成多份锁定而制造估值收益。估值变化不向钱包创造现金。

世界推演使用独立标签种子，闲谈次数不抽走战局随机数。对照示例：种子9、沈砚hold，未支援时刘备一方首季机会约0.414457，随机值0.551949，北方取得进展；开盘买25批粮草并交付刘备一方后，机会约0.585886，随机值不变，刘备一方取得进展。实际同季还可能包含其他交易商交付；不是承诺25批粮草在所有种子下必胜。

BYOK双来源独立保存，默认内存凭据，可选记忆遵循用户此前明确选择。TokenPay按官方Markdown公开协议接入S256 PKCE无回调授权码交换与模型目录，实际账号与合作后台未联调。Agent路径为公开配置导入、接入清单与页面字段约定；自动完成程度取决于Agent权限与浏览器工具，不能声称所有Agent都能自动填写凭据。

已实际执行65项Node检查和19项浏览器检查（主流程17项与连接专项2项）。结果文件与预览另附；没有真人试玩或平衡性效果数据。
