# 千秋交易所 · History Exchange

> 开源、本地运行的回合制历史交易策略游戏。当前为 **V0.2 可玩原型（情报酒馆 + BYOK 对手）**，非正式发行版。

在历史尚未发生之前，买入你相信的人。

## 立即开始（Windows / macOS / Linux）

1. 下载并解压完整 ZIP，保留 `index.html`、`style.css`、`engine.js`、`scenario.js`、`app.js` 在同一个目录。
2. **直接双击 `index.html` 即可运行游戏**，无需安装 Node.js、Python、React、服务器或任何依赖。
3. 在交易大厅选择人物股或事件合约，选择买入或卖出、输入份额，点击确认交易。
4. 点击「推进历史」：NPC 执行规则驱动的交易，年末到期合约按历史剧本结算；再进入下一回合。共 8 回合。
5. 点击「共创工坊」可手动编辑剧本 JSON、验证和导入导出，或使用自己的兼容 API 生成**待审核的剧本情报修改提案**。

> 文件模式可直接运行核心游戏。如遇部分浏览器针对 `file://` 的本地存储限制，可用下面的本地服务器方式访问。即使仅在内存中运行也可以通过「导出存档」保存进度。

### 可选：本地服务器运行

无需公网部署：

```powershell
cd path\to\history-exchange-local
python -m http.server 8765
```

浏览器打开 `http://localhost:8765`。没有 Python 也不影响通过 `index.html` 直接启动游戏。

### 开发和测试

需要 Node.js 18+，只用于**运行测试**，不是运行游戏所必需：

```powershell
node --test tests/engine.test.cjs tests/tavern.test.cjs
```

当前无需 `npm install`，不使用 CDN、在线字体或外部图片。

## 已经可以玩的内容

- 交易大厅：4 位人物、8 份 YES/NO 事件合约、真实 LMSR 自动报价、订单预估、份额限制与手续费。
- 回合系统：207、208、214、220、221、223、229、234 年，手动推进历史，每回合最多 5 笔玩家订单。
- 3 名规则型 NPC（趋势、情报、噪声）与 1 名交易对手沈砚；沈砚可使用 BYOK，默认使用固定种子的预设策略。
- 人物股：组合事件合约的原子多腿交易，已结算合约分红、除权后继续持仓。
- 资产页与赛季终局：余额、组合、NPC 对比、终局排行榜。
- 账本与存档：每笔交易、结算、自动做市商准备金与手续费池；优先 IndexedDB 自动保存，兼容 localStorage；可导入/导出完整 JSON 存档。
- 共创工坊：JSON 剧本编辑、验证、导入/导出、可选 BYOK 文案提案及人工批准 Diff。

## 经济规则（原型）

- 所有账户初始 1,000 虚拟金币；没有充值、提现、交易真实资金或平台奖金。
- 事件合约由 LMSR 定价，初始 YES/NO 报价为 50%/50%，每个市场流动性 b=100。
- 所有买卖采用实际成本函数差额结算，每条交易腿收取 1% 手续费；用整数微金币和微份额保存资金与资产。
- 玩家与 NPC 按同一套市场规则成交；NPC 不会自动读取合约结算结果；外部模型仍可能凭预训练知识知道历史。
- 人物股显示**尚未结算成分的加权中间价**，不是持仓总回报；已结算收益另外计入钱包。
- 这是「回放已知历史结局」的历史策略游戏，不是预测真实未来。存档在本机，无法防作弊。

## V0.2：情报酒馆与沈砚

交易大厅点击「去情报酒馆」，或使用左侧导航进入。每个交易回合有 **2 次探访**，与玩家的交易次数分开计算；探访消息人与交涉对手都消耗一次。

- 三位消息人：行商许掌柜、军中来客阿衡、游说之士季生。选择关注合约，自由提问，获得带角色偏见的线索。预设内容按种子固定，不读取合约最终答案；它是游戏判断，不是新增史料。
- 点击线索下方「带着这条线索找沈砚」，可分享同回合、同合约已获得的线索。分享最多影响 6 个百分点，单纯表态影响 2 个百分点，单回合累计影响上限为 12 个百分点。只有分享的线索会进入沈砚的观察。
- 推进历史时，沈砚通过现有 LMSR 引擎交易：每轮最多一笔、12 份，买入含手续费最多 20 金币；不允许卖空。可以主动观望；余额不足或订单不合法时不会伪造成交。其他三位 NPC 继续使用规则策略。
- 结算页展示沈砚的理由、实际成交或未成交原因、线索与最终结果的对照。探访、信念、角色对话、对手回合记录随 JSON 存档保留；模型会获得最近三个已结束回合的交涉与决策摘要。
- V0.1 存档可继续导入，原「价值」账户由沈砚接管，保留资金、持仓与历史成交；不会凭空增加初始资金。旧版程序不保证识别新玩法字段，修改前请保留旧存档备份。

### 启用模型玩法

1. 在酒馆点击「接入模型」，填写完整 `https://.../v1/chat/completions` 地址、模型名、自己的 Key。也允许本机 HTTP 端点。
2. 点击「启用 BYOK 玩法」。之后每次探访请求一次模型，推进历史为沈砚请求一次模型；切换页面和刷新不会自动调用。每轮至多两次探访加一次对手请求，完整八回合至多 24 次玩法请求，不含共创工坊与主动重试。
3. 请求最长等待 25 秒，超时、网络错误、非法返回会使用预设内容继续，并显示提示；点击「取消」不消耗探访，也不推进历史。模型回复仅作为角色语言或受限订单，不执行返回代码，不允许修改结算答案。
4. Key、端点、模型配置和启用开关仅存在于当前页面内存，不写入 IndexedDB、localStorage 或存档导出。刷新后需要重新配置，点击「清除 Key」立即关闭 BYOK 玩法。
5. 游戏上下文只发送当期可见新闻、所选线索、相应角色对话，以及沈砚自己的余额、持仓与报价；不发送整个剧本或未来结算字段。模型自身可能熟悉历史，史实模式无法彻底防止剧透。

接口必须允许网页跨域请求（CORS），仅兼容请求协议不代表一定能在浏览器里直连。Key 会随请求发送到用户填写的服务商；页面内存中的 Key 仍可被浏览器环境读取。不要将共用 Key 写入仓库。

### GitHub Pages

将完整静态文件放在 Pages 发布目录，保持 `index.html`、`style.css`、`scenario.js`、`tavern.js`、`ai.js`、`engine.js`、`app.js` 同目录。全部资源使用相对地址，支持仓库子路径；无需构建、后端、账号或运行时依赖。存档仍为浏览器本地存档，需要自行导入导出，不包含云同步与公共排行榜。

### 浏览器验收（仅开发用）

浏览器测试需要 Node.js 20+；核心单元测试仍支持 Node.js 18+。可选安装 Playwright 并运行：

```powershell
npm install --no-save playwright
npx playwright install chromium
node tests/browser-smoke.cjs
```

若本机已有浏览器，可设置 `HX_BROWSER_EXECUTABLE` 指向其可执行文件。截图和检查结果默认写入系统临时目录 `history-exchange-smoke`，可通过 `HX_TEST_OUTPUT` 指定目录。测试使用临时浏览器配置与模拟模型响应，不接触真实玩家存档，不需要 Key，也不会产生真实 API 费用。

## BYOK 共创（原型支持的边界）

1. 共创工坊可以直接修改 `scenario.js` 所描述的 JSON 内容（在界面中编辑并导出，不会覆盖源代码文件）。
2. 你可以填入 **自己选择的 OpenAI Chat Completions 兼容 API 端点、模型和 Key**，主动调用生成历史情报修改提案。
3. Key 仅保存在该页面 JavaScript 内存中，不进入存档、自动上传或提案 JSON。刷新页面后需要重新输入。
4. 模型仅返回建议的 `roundYear/news` 改动。界面展示旧文本与新文本 Diff；**必须由用户批准后才写入草稿**，还需要手动验证剧本并开启新游戏才能生效。
5. 不同 API 服务的 CORS 与协议支持不同：浏览器直接请求可能被拦截。这不是游戏主体的联网依赖。不要向不可信端点提交 Key。
6. 目前没有线上账号、开放投稿大厅、审核服务、版本注册表或 PR 自动提交。社区协作通过导出的 JSON 文件和将来的 GitHub PR 流程实现，详见 `COMMUNITY_ROADMAP.md`。

## 已知限制与下一步

- **本地可玩版优先**：此版本故意不用前期 PRD 中的 React/Vite/TypeScript 技术栈，以便零依赖、直接双击运行；进入正式开源版本时，可将无 UI 依赖的引擎逐步迁移到 TypeScript + Vitest，并保留存档迁移。
- 当前仅实现固定种子下的*确定性运行*，尚未实现完整独立的操作日志重新执行/哈希回放工具。
- 存档校验检查资金守恒、非负持仓和活跃合约份额，不具备防篡改签名或反作弊能力。
- 剧本中的历史结果是测试内容草案，`source` 字段仍为待校订的史料索引，不可宣称已完成史料级逐条审查。
- BYOK 是可选提案实验台，不是一个已经上线的「社区」；跨用户投稿、审核、合并、索引仍需单独实现。
- 当前只有浏览器网页，没有 Tauri/Windows 安装器，也没有 PWA Service Worker；静态文件复制到本地后可离线运行。
- 没有大模型也能玩，且默认游戏不调用任何外部网络 API。
